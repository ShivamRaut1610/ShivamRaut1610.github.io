## 🎨 Visual & Design Highlights

- **Aesthetic:** Dark Obsidian palette (`#0B0F17`) accented with electric cyan (`#06b6d4`), violet glow gradients, and frosted glass cards (`backdrop-filter: blur(16px)`).
- **Interactive Filtering:** Instant client-side DOM filtering for engineering case studies across:
  - *All Projects*
  - *AI & Autonomous Agents*
  - *Full-Stack & Systems*
  - *Hackathon Winners*
- **Architecture Philosophy Section:** Showcases the *"Deterministic Core vs. Probabilistic LLM Narration"* design pattern.
- **Embedded ATS Resume:** Interactive resume viewer with quick links to role-specific PDFs and GitHub repositories.
- **Performance:** Lightweight Vanilla CSS (`styles.css`) and modular ES6 JavaScript (`app.js`) with zero third-party framework dependencies.

## 🌐 Deploying to GitHub Pages (`shivamraut1610.github.io`)

To make this your primary root GitHub profile website:

1. Create a public repository on GitHub named **`ShivamRaut1610.github.io`** (or push to a repository named `portfolio`).
2. Run in terminal:
   ```bash
   cd portfolio
   git init
   git branch -M main
   git add .
   git commit -m "feat: initial commit of developer portfolio"
   git remote add origin https://github.com/ShivamRaut1610/ShivamRaut1610.github.io.git
   git push -u origin main
   ```
3. Your portfolio is immediately accessible globally at:  
   👉 **`https://shivamraut1610.github.io/`**
